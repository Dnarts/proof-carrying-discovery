# Целевая достаточность информации и атом исследовательского ремонта

**Александр Странд · v1.3 · 24 ноября 2026**

[Русский препринт (PDF)](repair_budget_atom_preprint_v1_3.pdf) · [LaTeX](repair_budget_atom_preprint_v1_3.tex) · [SHA-256](SHA256SUMS.txt)

Модель отвечает на вопрос: можно ли в заданном бюджете гарантировать безопасное действие, не устанавливая, какой из совместимых с наблюдениями миров истинный?

- [Lean-ядро](lean/repair_budget_atom_v1_3.lean) и [авторский журнал проверки](lean/repair_budget_atom_v1_3_VERIFICATION.log). В §6 PDF исправленный исходник назван `repair_budget_atom_v1_3_fixed.lean`. Здесь тот же файл опубликован под именем из манифеста; полный SHA-256 совпадает с записью в журнале.
- [Эталон и проверка сертификатов](python/reference_engine.py), [потоковая свёртка](python/fold_acc.py), [локальный клеточный автомат](python/local_ca.py), [тесты](python/test_suite.py), [пример сертификата](python/certificate_atom_B3.json), [авторский отчёт о прогонах](python/v1_3_verification_report.json). Код опубликован в распакованном виде; хеш исходного ZIP, упомянутый в статье, относится к архиву, а не к каталогу.
- Область Lean-ядра: скалярные целочисленные цены и детерминированные бинарные пробы. Указание на `(h, B)` в таблице 2 относится к трём приведённым результатам, а не к общей теореме о конгруэнции. Пять состояний относятся к потоковой свёртке, не ко всему КА. Клеточный эталон ограничен двумя действиями, одной бинарной пробой и горизонтом до одного шага; для больших горизонтов одношаговый просмотр не заменяет рекурсию `V_h`.

Для проверки целостности из этого каталога: `sha256sum -c SHA256SUMS.txt` (на macOS: `shasum -a 256 -c SHA256SUMS.txt`). Журналы и отчёт здесь приведены как авторские материалы; тесты при публикации не перезапускались.
