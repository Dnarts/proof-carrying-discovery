# Editorial note for the v2.5 translation

This is a faithful reading edition of the supplied manuscript. It does not add the benchmark from a separate same-version draft.

The two-axis disjointness theorem compares class refutation and a consistent gauge witness at the same public port and projected journal. The operational guards do not share that premise: language escalation tests the current port and journal, while port escalation uses a public gauge witness. Thus the theorem does not entail exclusive operational guards after refinement. The permitted steps can replay an unchanged port and log, so preservation of Valid is not a progress theorem. The concrete tapPort pair result is unaffected.

The Gate 13 obstruction requires an actual false indexed claim under both premises, not merely an ε-model or an unproved case. Gate 16 has eleven audited declarations per the table, citation [6], and verification log, although §7 says ten. The package total of 48, including 25 with no reported axiom dependencies, is correct.
