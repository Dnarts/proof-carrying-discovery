# Научная линия: от накопления законов к доказательной смене представления

[Главная страница](../README.md) · [English](RESEARCH_LINEAGE.en.md)

Цель исследования — не просто получить работающую программу, а предъявить **свидетельство недостаточности старого класса моделей, новую программу и точные основания её сертификации**. Это разные объекты с разными границами проверки.

## Последовательность

**I. Накопительное открытие — v1.1.1.** [Русский препринт](../PREPRINT_v1.1.ru.pdf), [код](../v1_1/). NAND/XOR, приобретение макросов и законов, условная цена сертифицированного поиска, перенос программы со счётчиком. Не универсальная гарантия ускорения.

**II. Контролируемое расширение языка — Lean.** [Теоремы](../formal/), [пояснения](FORMAL_RESULTS.ru.md). Условная безопасность эскалации при корректном свидетельстве невозможности и разделение DFA/1-DCA для заданного математического языка. Не доказана корректность произвольного внешнего монитора.

**III. Идентификация относительно модели — Gate 4B–5.** [Методологическая статья](../papers/hypothesis-language/HYPOTHESIS_LANGUAGE.ru.md), [конечный Lean](../papers/hypothesis-language/formal/). Пространство семантических гипотез, запросы единогласия, проверка канала, сохранение различий внутри расширенного автомата с основным слоем Rule 110. Не установлена принадлежность произвольного начального состояния четырём эталонам.

**IV. Gate 11–12 — доказательная эскалация.** [Актуальный препринт](../papers/hypothesis-language/gate11-gate12-v12.3/hypothesis_language_gate12_ru.pdf), [исходники Lean/Python](../papers/hypothesis-language/gate11-gate12-v12.3/gate12/), [полный бандл](../papers/hypothesis-language/gate11-gate12-v12.3/gate12_reproducible_bundle.zip). Конечное опровержение ограниченного класса; синтез двух канонических стековых программ; параметрическое доказательство их спецификации на всех словах и невозможности распознавания заданными классами DFA/1-DCA с любым конечным числом управляющих состояний.

Gate 6–10 — промежуточные опыты по изменению языка и конкурирующим операторам. Самостоятельные воспроизводимые комплекты **не каждого** этапа представлены в текущем дереве. Их нельзя автоматически считать следствиями теорем Gate 12.

## Разделение доказательных статусов

1. **Конечное отрицательное свидетельство** исключает DFA с не более чем \(k\) состояниями, но не все DFA для произвольного неизвестного языка.
2. **Универсальная теорема о классе** относится к точно определённому языку и явно заданному семейству машин; одной конечной выборки ответов недостаточно.
3. **Универсальное положительное доказательство** относится к конкретному каноническому стековому автомату при условиях параметрического Lean-проверяющего; корректность любого Python→Lean-транслятора из него не следует.
4. **Проверка причинной хронологии** требует полного упорядоченного журнала реальных обращений к оракулу. Сейчас Lean проверяет лишь выбранные исторические префиксы. Для двух задач осуществлено 88/107 обращений, сохранено 60/61 записей: полное отсутствие заглядывания вперёд не установлено.
